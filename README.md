 Imagify AI - Full Stack AI Image Generator SaaS

Imagify AI is a Full Stack MERN AI SaaS application where users can generate AI images using text prompts, purchase credits using Razorpay, and manage their account securely.

#  Features
User Authentication (JWT Based)  
Login & Registration System  
AI Text-to-Image Generation  
Credit Based Usage System  
Razorpay Payment Integration  
Buy Credits Functionality  
MongoDB Database Integration  
Responsive Modern UI  
Protected Routes & APIs  
MERN Stack Architecture  


#  Tech Stack

## Frontend
- React JS
- Vite
- Tailwind CSS
- Axios
- React Router
- React Toastify

## Backend
- Node JS
- Express JS
- MongoDB
- Mongoose
- JWT Authentication
- Razorpay API
